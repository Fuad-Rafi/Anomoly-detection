# Literature Review — Video Anomaly Detection

This folder holds the literature review, references, and downloaded PDFs for the
research roadmap in `../RESEARCH_ROADMAP.md`.

## Contents

| File | Purpose |
|---|---|
| `01_literature_review.md` | Full review: taxonomy, papers by era/method, datasets, gap analysis |
| `02_references.bib` | BibTeX entries for the papers |
| `pdfs/` | Downloaded PDFs (arXiv / open-access only; paywalled papers listed in the manifest) |
| `manifest.md` | Download status of every paper, with links |

## How to read

1. Start at `01_literature_review.md` §"Gap analysis" to see where this project sits.
2. Use `02_references.bib` in Zotero/Overleaf for the write-up.
3. PDFs are named by a short slug (see `manifest.md`).

## Notes

- Many CVPR/ICCV/ECCV papers are IEEE/CVF-paywalled and have no legal public PDF; the
  manifest marks these and links the official landing page.
- arXiv versions are downloaded where they exist.
